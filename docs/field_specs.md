# ABU Robocon 2027 フィールド仕様書

出典：`docs/Robocon_2027_Rulebook_v1-1.pdf`（公式ルールブック英語版、全28ページ）。
以前は非公式日本語訳（2026年8月23日版）を出典としていたが、正式PDF入手後に
数値（特に競技物の重量・ムスティカ直径）を照合し、誤りがあった箇所を修正した。

この文書は、シミュレーター実装（2D/3D共通）で使う `field_constants.py` の元データ。
数値は原則ルールブック本文からの転記。**位置座標（原点からの配置）はルールブックに
明記が無いため、設計判断として仮に置いた値**を含む。それらには「要確認」を付けた。

## 座標系の設計判断

鮮明な画像（フィールド.png）を拡大精読した結果、寸法図は**フィールドの角を基準に
各要素のオフセットを積み上げていく方式**で描かれていることが分かった。これに倣い、
座標系は以下のように置く。

- 原点：ランプ側（赤チーム）の近い角 (0, 0)
- U軸：ストレージエリア沿いの辺（0〜11,000mm）
- V軸：スタートゾーン沿いの辺（0〜11,000mm）
- 赤/青は中央分離フェンスを挟んで線対称（画像でも対称配置を確認）
- Z軸：グラウンド面を Z=0 として高さ方向

赤チーム側の座標を上記で確定し、青チーム側は中央線に対して鏡映変換すれば求まる。

## まとめ：座標復元の状況

高解像度画像を直接精読したことで、サイズ・オフセットともにほぼ全数値を確認できた。
残る不確定要素は、赤/青の分割線が「フィールド対角線に沿うか、辺に平行な中央線か」
という点のみ（画像上は視覚的に対称に見えるが、分割線の正確な向きまでは寸法線から
断定しきれない）。ただし2Dシムの実装上は、対称配置という仮定のまま進めて問題ない
レベルの確度に達している。
